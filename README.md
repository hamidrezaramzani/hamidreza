# Hamidreza Ramzani — Portfolio

Personal portfolio for [Hamidreza Ramzani](https://www.thehamidreza.ir), a frontend developer.

## Stack

- Next.js 14
- React 18
- Tailwind CSS
- Framer Motion
- next-themes

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
